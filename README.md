## Looking for Beauty: Python Code 
This repository contains separate Python code files for the statistical analyses and figures included in my bachelor's thesis "Looking for Beauty: The Relationship Between Aesthetic Experience and Eye Movements"

"results_hypothesis1.py" contains code for the statistical analysis of Hypothesis 1 (1a, 1b and 1c).

"results_hypothesis2.py" contains code for the statistical analysis of Hypothesis 2 (2a, 2b, 2c and 2d).

"exploratory_analysis.py" contains code for the exploratory statistical analysis conducted after the analysis of previously determined hypotheses.

"example_rdm.py" contains code for Figure 2.

"example_scanpath.py" contains code for Figure 3.
